# Machine Learning Specialization – DeepLearning.AI & Stanford Online

## Overview

This repository contains programming assignments, practical exercises, and implementations developed throughout the **Machine Learning Specialization**, offered by DeepLearning.AI and Stanford Online.

The specialization provides a comprehensive introduction to modern machine learning, covering supervised learning, advanced learning algorithms, unsupervised learning, recommender systems, and reinforcement learning.

The repository showcases the implementation of machine learning algorithms, mathematical foundations, model training techniques, and practical applications using Python.

## Course Structure

The repository is organized into three main courses:

### C1 – Supervised Machine Learning: Regression and Classification

Introduction to supervised learning techniques for predicting numerical values and classifying data.

**Topics covered:**
- Linear Regression.
- Multiple Linear Regression.
- Gradient Descent.
- Feature Scaling.
- Polynomial Regression.
- Logistic Regression.
- Regularization.
- Classification Algorithms.
- Model Evaluation.

### C2 – Advanced Learning Algorithms

Exploration of advanced machine learning techniques, focusing on neural networks and decision tree-based algorithms.

**Topics covered:**
- Artificial Neural Networks.
- Neural Network Architecture.
- Forward Propagation.
- TensorFlow.
- Multiclass Classification.
- Decision Trees.
- Random Forests.
- Tree Ensembles.
- Model Optimization and Evaluation.

### C3 – Unsupervised Learning, Recommenders, and Reinforcement Learning

Introduction to learning techniques that identify patterns in unlabeled data, provide personalized recommendations, and optimize decisions through interaction with an environment.

**Topics covered:**
- Unsupervised Learning.
- K-means Clustering.
- Anomaly Detection.
- Recommender Systems.
- Collaborative Filtering.
- Content-Based Filtering.
- Reinforcement Learning.
- State-Action Value Functions.
- Policy Optimization.

## Learning Objectives

This repository demonstrates practical knowledge and implementation of fundamental machine learning concepts, including:

1. Understanding the mathematical foundations of machine learning.
2. Implementing supervised learning algorithms.
3. Training and evaluating predictive models.
4. Building neural networks for classification tasks.
5. Applying unsupervised learning techniques to discover patterns.
6. Understanding recommender systems and reinforcement learning.
7. Optimizing model performance and generalization.

## Purpose

This repository serves as a technical portfolio documenting the development of machine learning knowledge through practical implementations and programming assignments.

It highlights the transition from foundational predictive algorithms to more advanced machine learning architectures and learning techniques.
